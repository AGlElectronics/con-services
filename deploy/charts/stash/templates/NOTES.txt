Stash {{ .Values.image.backend.tag }} is installed in namespace {{ .Values.namespace }}.

1. Watch the pods start (the backend migrates its database first):

     kubectl get pods -n {{ .Values.namespace }} -w

2. Check the backend's health:

     kubectl exec -n {{ .Values.namespace }} deploy/stash-frontend -- {{ if .Values.internalTLS.enabled }}curl -s --cacert /etc/conservices-internal-ca/ca.crt https{{ else }}wget -qO- http{{ end }}://stash-backend:{{ .Values.backend.port }}/api/health

   Expect: {"status":"ok","database":"ok",...}
{{- if .Values.route.enabled }}

   Check that the gateway accepted the route (ACCEPTED and RESOLVEDREFS True):

     kubectl get httproute -n {{ .Values.namespace }} -o custom-columns=NAME:.metadata.name,ACCEPTED:.status.parents[0].conditions[?(@.type=='Accepted')].status,RESOLVEDREFS:.status.parents[0].conditions[?(@.type=='ResolvedRefs')].status
{{- end }}
{{- if or .Values.route.enabled .Values.ingress.enabled }}

3. Open https://{{ ternary .Values.route.host .Values.ingress.host .Values.route.enabled }} and sign in.
{{- end }}

4. Pair with Den: Den -> Admin console -> Modules -> Pair, then in Stash
   Settings -> Den connection, paste the pairing URL.
