Desk {{ .Values.image.backend.tag }} is installed in namespace {{ .Values.namespace }}.

1. Watch the pods start. The backend pod shows Init:0/1 while the migrate
   initContainer applies database migrations:

     kubectl get pods -n {{ .Values.namespace }} -w

2. Check the backend's health:

     kubectl exec -n {{ .Values.namespace }} deploy/desk-frontend -- wget -qO- http://desk-backend:{{ .Values.backend.port }}/api/health

   Expect: {"status":"ok","database":"ok",...}
{{- if .Values.ingress.enabled }}

3. Open https://{{ .Values.ingress.host }}, sign in as a desk-admin and add
   a mailbox under Mailboxes. Use "Test connection" before saving.
{{- end }}

4. Pair with Den: Den -> Admin console -> Modules -> Pair, then in Desk
   Settings -> Den connection, paste the pairing URL.

The backend runs exactly ONE replica (mail fetcher). Do not scale it.

Docs: https://aglelectronics.github.io/con-services/modules/desk/setup/
